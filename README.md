# SpendWise - Personal Budget & Expense Tracker

## Project Description

SpendWise is a simple Personal Budget and Expense Tracker website designed to help users organize their money and keep track of their daily expenses.

The website allows users to view their budget summary, enter expenses, select expense categories, and view previously recorded expenses in a table.

## Project Name

**SpendWise - Personal Budget & Expense Tracker**

## Repository Name

## Files Included

### 1. index.html

The `index.html` file provides the structure and content of the SpendWise website.

It contains:

* Website header and title
* Introduction section
* Budget summary cards
* Expense form
* Expense categories
* Expense table
* Budgeting tips
* Footer

The form uses different HTML input types such as:

* Text input
* Number input
* Date input
* Select/drop-down list
* Submit button

The expense table uses `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, and `<td>` elements to organize the expense information.

## Main Features

### Budget Summary

The website displays:

* Total Budget
* Total Expenses
* Remaining Balance

Example:

* Total Budget: KSh 50,000
* Total Expenses: KSh 27,500
* Remaining Balance: KSh 22,500

### Expense Form

Users can enter:

* Expense name
* Amount
* Category
* Date

The category drop-down contains:

1. Food
2. Transport
3. Education
4. Shopping
5. Rent
6. Bills
7. Entertainment

### Expense Table

The website displays sample expenses in a structured table.

The table includes:

* Expense
* Category
* Amount
* Date

### Budgeting Tips

The website also provides simple financial management tips to help users manage their money responsibly.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. The SpendWise website will appear.
